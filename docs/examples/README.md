# 合成导入样例

[题库样例](synthetic-questions.xlsx) 的题干、选项和解析均为本次仓库改进自编，采用演示笔数、演示色片和演示答题约定三个虚构场景。包含 `single`、`multiple`、`judge` 各 1 题，每题 1 分，来源列统一为 `知试自编合成导入样例`，来源编号为 `SYNTHETIC-001` 至 `SYNTHETIC-003`。它只包含一个 `questions` 工作表，字段与管理端题库导入模板一致，可用于导入验证和三题考试演示。

[应考名单样例](synthetic-exam-roster.xlsx) 包含一个 `exam_roster` 工作表，姓名、部门、岗位和分组均为合成占位信息，邮箱使用 `example.com`。它可验证草稿考试的名单导入；导入只创建 pending 账号和当前考试 scope，不会绕过注册或自动授予考试访问权限。占位邮箱不能接收真实邮件。要演示邮箱验证码登录与邀请流程，应在隔离测试环境把邮箱替换为自己控制的测试收件地址，配置 SMTP，再按正常注册、发布、邀请和答题流程操作。

两份样例都不包含根目录真实题库转换资产的题目，不来自员工名单或正式考试数据。真实转换资产的用途、统计与未确认授权状态见 [导入说明](../import-templates.md#已跟踪的题库转换资产)。本目录只提供导入演示数据，不证明现网已完成对应验收。
